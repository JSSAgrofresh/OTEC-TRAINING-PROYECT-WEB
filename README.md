## 📌 Descripción

**OTEC TRAINING PROJECT WEB** es una aplicación frontend para gestión y visualización de contenidos de formación OTEC.  
El proyecto utiliza una arquitectura moderna basada en componentes reutilizables.

## 🧱 Stack tecnológico

- React 18
- TypeScript
- Vite
- React Router DOM
- CSS

## 📂 Estructura base

```bash
src/
 ├─ assets/
 ├─ components/
 ├─ data/
 ├─ hooks/
 ├─ layouts/
 ├─ pages/
 ├─ routes/
 ├─ services/
 ├─ styles/
 ├─ types/
 └─ utils/
```

## ⚙️ Instalación y uso

```bash
git clone https://github.com/Proyect2026/OTEC-TRAINING-PROYECT.git
cd OTEC-TRAINING-PROYECT
npm install
npm run dev
```

## 🏗️ Scripts disponibles

```bash
npm run dev      # entorno desarrollo
npm run build    # build producción
npm run preview  # vista previa build
```
